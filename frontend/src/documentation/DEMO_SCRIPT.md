TripSync – Project Demonstration Script

1. Introduction

Good morning everyone.

Our project is called TripSync – Travel Booking and Expense Management System.

The main purpose of this project is to make travel planning easier by combining transport booking, hotel reservations and trip expense management in one application.

2. Home Page Demonstration

First, we open the TripSync home page.

The home page displays the travel search section where users can select:

- Transport type
- Starting location
- Destination
- Travel date
- Number of passengers

Click Search Trips to view the available travel options.

3. Transport Booking Demonstration

Next, we demonstrate the transport booking module.

1. Select a journey.
2. Choose the preferred seat.
3. Enter passenger details.
4. Confirm the booking.

The application displays a booking confirmation.

We can also open My Bookings to view saved bookings and use the seat-changing option when another seat is available.

4. My Trips Demonstration

The My Trips section displays trip information, including journey details and passenger information.

It helps users view their synchronized trip records.

5. Hotel Stay Demonstration

Next, we open the Hotel Stay section.

1. View the available hotel options.
2. Enter guest details.
3. Select check-in and check-out dates.
4. Enter the number of guests.
5. Confirm the reservation.

The application displays the reservation confirmation.

6. Expense Management Demonstration

Next, we open Trip Expense Management.

Users can add expenses by entering:

- Expense name
- Amount
- Person who paid
- Date
- Number of people sharing

The application supports equal splitting and custom splitting.

After saving, the expense appears in the All Trip Expenses section. Users can also view settlement information.

7. Technology Demonstration

Our project uses:

- HTML, CSS and JavaScript for the frontend.
- Java Spring Boot for the backend.
- MySQL for database storage.
- Vite for frontend development.

The frontend communicates with the backend, and the backend manages database operations.

8. Conclusion

TripSync combines transport booking, hotel reservations and expense management in one web application.

This project helped us understand frontend development, backend development, database connectivity and full-stack application development.

Thank you.
